# Security Policy

## Supported version

Security fixes target the latest revision on `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Include the affected command or file, a minimal reproduction, expected impact, and any safe mitigation you have tested.

Do not include secrets, private source code, or destructive proof-of-concept payloads in a public issue. You should receive an acknowledgement within seven days. Public disclosure is coordinated after a fix or mitigation is available.
